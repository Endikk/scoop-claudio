# scoop-claudio

[Scoop](https://scoop.sh) bucket for [Claudio](https://github.com/Endikk/Claudio), your real Claude
quotas on your Windows desktop.

```powershell
scoop bucket add claudio https://github.com/Endikk/scoop-claudio
scoop install claudio
```

The manifest in `bucket/` follows each Claudio release. Claudio is also on winget:
`winget install Endikk.Claudio`.
